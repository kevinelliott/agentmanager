AI coding agent manager for the terminal

AgentManager finds the agent CLIs on your machine, checks each against npm, PyPI and Homebrew, and installs or updates any of the 309 in its catalog. Runs on macOS, Linux and Windows.

Features of the agentmgr CLI

Installs agents by npm, pip or Homebrew

Also pipx, uv, cargo, go and native installers. Add -v to watch the live output.

  • npmnpm install -g @sourcegraph/amp
  • Homebrewbrew install sourcegraph/amp-cli/amp
  • pip, pipx and uvuv tool install aider-chat
  • cargocargo install abtop
  • gogo install github.com/charmbracelet/crush@latest

Prints agent data as JSON or YAML

Every command takes --format. REST and gRPC APIs and a Go library do the rest.

Questions about AgentManager

Short answers on platforms, updates and scripting. The README on GitHub holds the full command reference.

Ask a question on GitHub

Which systems does AgentManager run on?

macOS on Intel and Apple silicon, Linux on amd64 and arm64, and Windows on amd64. Releases also carry .deb, .rpm and .apk packages.

Does the CLI need a network connection?

Not to start. The catalog is embedded in the binary, so agent list and catalog list work before the first remote refresh.

Does AgentManager find duplicate installs?

Yes. Each install gets its own row with its method, so an npm copy and a Homebrew copy are listed and updated separately.

Can the CLI show an installer's output?

Yes. Add -v to agent install or agent update to stream the live output of brew, npm, pip or a native installer.

Does AgentManager tell me about updates?

Yes. The background helper sits in the system tray and notifies you when an agent has a newer release.

Can other programs call AgentManager?

Yes. Commands print JSON or YAML with --format, and REST and gRPC APIs and a Go library are included.

How do I update AgentManager itself?

Run agentmgr upgrade, or re-run the install script. With Homebrew, use brew upgrade agentmanager.

What does AgentManager cost?

Nothing. AgentManager is free and open source under the MIT licence, with its source on GitHub.

Install AgentManager with one command

The script downloads the release for your system, verifies its SHA-256 and installs agentmgr without sudo. On Windows, take the .zip from the latest release.

  • agentmgr agent list

    Lists detected agents with installed and latest versions.

  • agentmgr agent install claude-code

    Installs an agent from the catalog.

  • agentmgr agent update --all

    Updates every agent that has a newer release.

  • agentmgr tui

    Opens the interactive terminal interface.

  • agentmgr doctor

    Checks system health and configuration.
